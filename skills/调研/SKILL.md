# 调研怎么做

调研是为了让他（材料工程师）能做决定，不是为了攒资料。每一步都落到知识库里，下次不用重来。

## 步骤
1. 用 plan 列步骤。先把问题说清：要回答什么、为哪个课题、哪个站点、做完他能决定什么。
2. 先看已有的：用 records 查知识库（知识库）里的 命题、文献，用 find 查产品库里相关的实验和测试。已有的结论不要重查。
3. 找资料：web 搜论文、专利、技术资料（搜的词会发到外面：只用化学名、CAS 号、通用术语，不用我们的内部编号、产品名、配方号、客户名）；能取到原文就读原文的关键段落。每条资料存一条"文献"（标题、作者、年份、类型、链接或路径、取舍 留/舍、理由、要点）。舍掉的也记，写清为什么舍（不相关、条件不同、质量差）。
4. 写命题：每个结论一条"命题"——
   - 陈述：一句能单独读懂的话，讲事情本身（例："DMAP 作终止剂时，110 °C 以上会和 TsOH 成盐析出"）；
   - 适用范围：在什么体系、温度、浓度下成立；
   - 状态：待验证（只有文献或推断）/ 成立（有我们自己的数据支持）/ 否定；
   - 把握：0–100，写在字段"把握"里；为什么这个把握写在说明里（例"两篇文献一致，但体系不同"）。
   - 关联：出处 → 文献；证据 → 我们库里的实验或测试记录；属于 → 课题。
5. 几条命题能推出新结论时，存一条"推理链"：前提 → 几条命题，结论 → 一条命题，说明写推理。
6. 事实和推断分开：文献里写的、我们测到的，是事实；你推出来的，写成推断，把握不超过 70 %，状态是待验证。
7. 收尾：用 brief 存一份"调研"简报（kind=调研）：一句话结论；发现（每条带 [[命题]] 或 [[文献]]）；还缺什么证据；建议做什么实验去验证（带 task）。能写预测的，按技能「预测和验证」写好预测。

## 说人话
- 结论先说，数字带单位和出处。
- 不确定就说不确定，写清把握和原因；不要把推断写成事实。
- 他问的是一件事，就围绕这件事；顺带发现的写进"发现"，不展开。
