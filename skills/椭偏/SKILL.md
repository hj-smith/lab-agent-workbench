# 椭偏膜厚

## 库里有什么（产品A、产品B 两个库都有）
- `膜`：一片膜在一个测试日的读数块（旧程序的"样品块"）。id `ell-SI-…`，名字"编号 · 测试日"（同名同日多块加 #1 #2）。
  字段：样品编号、原名（汇总表原文）、测试日、配方编号（跨模块关联用；参比为空）、对应状态（已确认 / 同编号 / 别名规则 / 参比 / 待对应）、
  转速 rpm、烘烤温度 ℃、烘烤时间 s、处理（SolvA）、处理时间（原文如 2min）、后烘温度 ℃、后烘时间 s、变体（重测、稀释3倍）、
  条件来源（样品名 / 表脚注 / 默认（用户确认）/ 手改；测试日来自表页名或文件名）、工作簿、页名、剔除、旧id。
- 表 `读数`（挂在膜上）：读数id、行、阶段（before_solva=处理前，after_solva_1=处理后）、次数、膜厚 / nm、n 193、k 193、n 248、k 248、n 633、k 633、MSE、溶解、原表平均行、其它（原解析行其余字段）。
- `椭偏测试日`：一天测的一批膜。膜 →测于→ 测试日。原件 xlsx 挂在膜的 files 上。
- 设置：`椭偏.容差`（12 项）、`椭偏.默认条件`（没写的按 250℃/120 s、处理 2 min、后烘 250℃/60 s）、`椭偏.配方别名规则`、`椭偏.参比选择`、`椭偏.忽略的提示`、`椭偏.其它规则`。

## 常用查法
```python
from lab import store
from lab.sci import ellipsometry as ell
lib = store.open('产品A')
lib.sql('SELECT name, 样品编号, 测试日, 配方编号, 转速, 烘烤温度, 烘烤时间 FROM "膜" WHERE 测试日=?', ('2026-09-17',))
cols, rows, meta = lib.table('ell-SI-cbd9fe2e53e5f9790890', '读数')          # 一片膜的全部读数
lib.results('椭偏.块统计', kind='膜')                                         # 已算好的块统计
lib.get('ell-…')['results']['椭偏.块统计']['value']
```
SQL 取结果：`SELECT r.name, json_extract(x.value,'$."各阶段"[0]."损失率 %"') FROM results x JOIN records r ON r.id=x.record_id WHERE x.method='椭偏.块统计'`。

## 能算什么（`lab.sci.ellipsometry`，都返回字典）
- `film(lib, 膜)`：块统计。处理前/后均值 nm、SD nm（ddof=1）、CV %、n；损失 nm、损失率 %、保留率 %、溶解；n/k/MSE 处理前后；建议离群读数（IQR 1.5，≥4 点）。
- `groups(lib, test_date=None, formula=None, group_by=None)`：组统计。组＝配方＋转速＋烘温＋烘时＋处理＋测试日＋变体。
- `pairing(lib, test_date=None)`：每组推荐参比（规则 A）。
- `compare(lib, candidate, reference=None)`：candidate 可写 "PA-T22C@2026-09-17"、膜 id 或组key；不给 reference 用推荐的。给差值、相对差、百分点差、12 项判定和整行判定。
- `quality(lib, 膜=None)`：质量提示（只提示，不剔除）。
- `compute_all(lib)`：全部重算并存 results（膜：椭偏.块统计、椭偏.质量提示；测试日：椭偏.组统计、椭偏.参比判定）。

## 业务口径
- 块统计只用单点（通常 6 个），原表"平均"行不参与；CV＝SD/|均值|×100。
- 损失率＝(前−后)/前×100，保留率＝后/前×100；标"溶解"或"\"＝溶解，后＝0、损失率 100 %。只有一个阶段的工作簿按"常规单阶段"，没有损失率。
- 组均值＝各块均值再平均，组 SD/CV 是块与块之间；pooled SD 用全部单点；组损失率＝各块损失率平均，另给"不含溶解"。
- 参比规则 A：只用同系列标准参比、测试日不晚于样品、有数据的组；先比条件不同的项数少，再比日期近；同天同条件自动选，
  否则选最近的更早同条件组，否则"要人选"（例：1500 rpm/400℃ 的 T17、T18 和 REF01 400℃ 那组转速不同，要人选）。
- 判定：每项 better / within / worse / not_evaluable / not_applicable，整行取最差。容差 null 的项不判。
- 默认条件是计算时补的：条件来源是"默认（用户确认）"的值，改了 `椭偏.默认条件` 后重算就跟着变。

## 坑
- 膜厚单位 nm（用户 2026-10-22 确认）。处理时间是文字（"2min"），不是秒。
- 同一工作簿里 T18A 有 3 块，条件不同（1500/900 rpm、400/250℃），分成 3 组，不要混在一起平均。
- 剔除写在膜的字段 `剔除`：[{读数id, 范围: 整点/膜厚/几列, 列: ["膜厚 / nm"…], 原因}]，改完跑 compute_all。剔除和改条件要先问用户。
