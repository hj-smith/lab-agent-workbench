# 文献问答

他问一个问题（例："添加剂H在光照下稳定吗"），要的是能拿来做决定的回答，不是一堆摘要。

## 回答问题
1. 用 literature 的 find 找（中文问一遍，再用化学名的英文说法问一遍，例 "additive H photostability"）；页面上带过来的几条先看。
2. 用 records 的 get 读最相关的几条全文（文献的"要点""理由"，命题的"说明""适用范围""验证缺口"，以及关联的出处和证据）。文献里写了页码的，引用时带上。
3. 回答：
   - 第一句就是结论；不确定就直说"库里的证据还定不了"，写清差在哪。
   - 每一句后面标出处：[[文献名]] 或 [[命题]]；我们自己的数据写 [[记录名]]。
   - 事实（文献写的、我们测的）和推断（你推出来的）分开写，推断标"推断"。
   - 舍掉的文献也有用：它为什么被舍（体系不同、只有摘要）要说出来，别把它当证据。
   - 文献的条件和我们的不一样时（温度、溶剂、酸碱、是不是聚合物），明说不能直接外推。
4. 库里不够时：说缺什么，建议"按技能「调研」去外面查"（要外搜由他点头；搜的词只用化学名、CAS、通用词）。不要自己跑去外搜。
5. 他认可的新结论，问他要不要写成命题（按技能「调研」第 4 步的格式）。

## 每周文献监测（规则「文献监测」）
1. literature check 查一遍（发出去的只有监测主题里的检索式）。
2. literature leads status=待看 看新到的。每条按标题和摘要判断：和哪个课题、哪条命题有关，值不值得他花时间读。
3. 用 literature screen 写：
   - 相关度：高 = 直接回答我们课题里的问题、或和某条命题的结论相关（支持或反驳）；中 = 同类体系或方法，可能借鉴；低 = 只是用了同样的词。
   - 意见：一句话，说清为什么（例"讲添加剂H在酸性条件下还原显色物种，正好对着 AddH 课题'褪色是还原还是酸碱变化'那条命题"）。
4. 只写相关度和意见；留还是舍由他在 知识 → 文献 里点。
5. 收尾一两句：这周新到几篇、高相关的是哪几篇、各对着哪个课题。一篇高相关都没有就直说。
6. 某个主题连着几周全是低相关，建议他改检索式（给出改法），不要自己改。

## 全文 PDF（人拖进来的）
- 文献上有"全文页数"、"PDF"的，是人把整篇论文拖进来的：每一页的文字存在这条文献的表"全文"（列：页、文字）。
- literature find 命中全文时会带 page（第几页）。回答引用全文时写"[[文献名]] 第 N 页"，人点得开那一页。
- 要细读：records 读这条文献的 series「全文」，挑相关的几页读，不要整篇塞进来；读完可以把要点补进这条文献的"要点"（写明哪几页）。
