# NK 光学常数

## 库里有什么（产品A 库）
- `NK谱`：一个仪器导出 txt（椭偏拟合得到的 n、k）。id `nk-<旧id>`，名字＝谱名（例 PA-T22A-3、PA-T13-1SolvA）。
  字段：谱名、分组、轮次、纳入、纳入重复性、文件名、内容指纹（SHA-256）、点数、起始波长 nm、终止波长 nm、编码、分隔符、波长单位、旧id。
  曲线 `nk`：列 `波长 / nm`、`n`、`k`（清洗后：只留有限数、波长>0、按波长排序、重复波长取平均）。每条约 1082 点，189.3–1000.2 nm。
- `NK分组`：同一样品的重复谱（文件名去掉 -1…-6），NK谱 →属于→ NK分组。`NK轮次`：T11…T22、参比 REF01，NK分组 →属于→ NK轮次。
- 设置：`NK.分析参数`（目标波长 193/248/365/405/436/532/633/780/940、波段 UV 190–400/可见 400–780/NIR 780–1000、网格 1 nm、异常筛查参数）、
  `NK.参比`（现在＝组均值｜REF01-250-120s-SolvA）、`NK.导出方案`（T13 处理前后差值专题、T16 自定义四图组合）、`NK.对比来源`（T22A–E 组均值）、`NK.配对`。

## 常用查法
```python
from lab import store
from lab.sci import nk
lib = store.open('产品A')
lib.sql('SELECT name, 分组, 轮次, 纳入, 纳入重复性 FROM "NK谱" WHERE 分组=?', ('PA-T22A',))
cols, rows, meta = lib.table('PA-T22A-3', 'nk', kind='NK谱')
s = nk.Session(lib)                       # 一次读全部谱（约 30 s），后面几个函数都可以传 session=s
nk.at(lib, 'PA-T22A', 193, session=s) # 组名 → 组均值 ± σ；谱名 → 单条
```
已算好的：`lib.results('NK.目标波长', kind='NK谱')`、`lib.results('NK.组均值', kind='NK分组')`、`NK.异常筛查`、`NK.配对差值`（挂在处理前那条谱上）。

## 能算什么（`lab.sci.nk`）
- `at(lib, 谱或组, 波长)`：n、k、ε1、ε2、α（cm⁻¹）、R、穿透深度（nm）；组另给 σ(n)、σ(k)、重复数。
- `group(lib, 组, wavelengths=None)`：组均值 ± σ（各目标波长）＋重复性摘要（平均σ、最大σ及波长、共同点数）。
- `compare(lib, 谱或组, reference=None)`：共同网格上 RMSE、MAE、最大差、相关系数；目标波长 Δn、Δk、Δn 相对 %。
- `anomalies(lib, 组=None)`：同组 MAD 修正 z 筛查＋突跳，只给候选和理由。
- `pairs(lib)`：处理前后配对建议（名字去掉 SolvA 一一对应）；`pair_delta(lib, 处理前谱, 处理后谱)`：Δn＝后−前、Δk。
- `compute_all(lib)`：全部重算存 results。

## 业务口径
- 取某波长的值一律线性插值：正好有这个波长的点用原值，否则相邻两点线性插值，超出实测范围留空，不外推。
  不要用"离 193 最近的点"（193.19 nm），k 会差到 0.0014。
- 组均值在统一 1 nm 网格（全部纳入谱的共同范围）上算：每个波长组内全部重复都有值才算；σ 是样本标准差（ddof=1）。
- 只有"纳入"且"纳入重复性"都为真的谱进组均值；组内少于 2 条就没有组均值。
- 异常筛查只给证据，去不去掉由人定：改 `纳入重复性` 字段后重算。改纳入标记、换参比要先问用户。

## 坑
- 谱的测试日期、膜厚、配方都没记录；和椭偏、配方的对应只能靠名字（谱名去掉 -1…-6 和 SolvA 就是样品编号，带条件的如 T18A-400-90-1500）。
