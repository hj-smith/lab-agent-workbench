# 研发工作台

一个以智能体为核心的材料研发工作台网页。助手（大模型）是核心，软件给它当手脚：查库、算、作图、写报告。人在网页上看、改、拍板。

这个仓库只有程序，**不带任何项目数据**：没有实验记录、配方、测试数据、SOP、用户和密钥。第一次启动是一个空的工作台。

## 能做什么

- **助手**：右边一直在的对话栏，会用工具查库、算、写报告；干活时也能插话改方向；先问清单里的事先发卡片问人。
- **每天和每周的主动工作**：晨报、每周复盘、文献监测、文件夹自动导入，在"助手 → 规则和定时"里开关和修改。
- **通用数据库**：任何实验、测试都能建类型、导入（Excel、CSV、仪器导出文件）、改、删（回收站）、导出。
- **专业计算**：GPC 分子量（基线、积分区间、标准曲线、叠加对齐和归一）、椭偏膜厚、n/k 光学常数、储存老化（UV）、配方称量和工单、树脂合成设计和批记录。
- **知识**：文献库（PDF 全文、按页搜）、命题、推理链，问答带出处。
- **手机页**：称量、批记录、拍照记一笔。
- **登录和权限**：本机管理端不用登录；外网访问口要账号、密码、验证器；邀请链接让人自己设账号；每个库可以给看 / 填 / 改。
- **微信推送**：用微信公众号（测试号也行）扫码绑定，卡片和通知推到微信。

## 怎么跑

要 Python 3.12 和 Node.js 20 以上（Node 只给树脂计算用）。

```bash
pip install -r requirements.txt
```

Windows 上双击 `启动.cmd`，或者自己设环境变量再启动：

| 变量 | 意思 | 默认 |
| --- | --- | --- |
| `LAB_HOME` | 数据放在哪个文件夹（库、设置、用户都在这里） | 程序旁边的 `data` |
| `LAB_PORT` | 本机管理端端口（不用登录，只给这台电脑用） | 8850 |
| `LAB_PUBLIC_PORT` | 外网访问口端口（要登录，内网穿透只指向它） | 不开 |
| `LAB_NODE` | node 的路径 | `node` |
| `LAB_LOG` | 日志文件 | 不写文件 |

```bash
python -X utf8 -c "from lab.server import main; main()"
```

然后打开 http://127.0.0.1:8850 。在"设置"里加一个模型接口（OpenAI 兼容、Anthropic、Gemini 等格式都行），密钥只存在本机数据文件夹的 `auth.json` 里。

## 文件夹

- `lab/`：服务和智能体（`loop.py` 智能体循环、`kernel.py` 事件和对话、`store.py` 通用数据库、`sci/` 各种专业计算、`server.py` 网页接口）
- `web/`：网页（不用打包，直接是 ES 模块）
- `skills/`：给助手看的技能说明
- `resin-kernel/`：树脂合成的计算核心（Node）
- `docs/`：设计说明
